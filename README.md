# FloodDuo: A Dual Foundation-Encoder Architecture for Generalizable High-Resolution Flood Mapping

FloodDuo maps open water in high-resolution (3 m, 4-band B/G/R/NIR PlanetScope) imagery by
pairing two **frozen** vision foundation encoders that carry complementary information:

- **DINOv3-L** (ViT-L/16, RGB) — sharp spatial / boundary detail.
- **Clay v1.5** (ViT-L/8, 4-band BGRNIR) — wavelength-conditioned spectral discrimination.

The frozen encoders are adapted with lightweight trainable modules (an in-block frequency-domain
**Earth-Adapter (EA)**, plus post-hoc **ADAC** atrous depth-wise and **PPAdapter** pyramid-pooling
adapters), and their branch predictions are merged by a **disagreement-gated fusion** whose per-pixel
Jensen–Shannon disagreement doubles as a label-free reliability signal, before a LinkNet decoder.

Only ~65 M parameters are trained against ~614 M frozen.



## Results (leave-one-region-out, region-mean water IoU)

| Model | FloodPlanet | UFO |
|---|---|---|
| **FloodDuo (ours)** | **0.728** | **0.819** |
| TerraMind-L | 0.700 | 0.789 |
| DOFA-L | 0.687 | 0.766 |
| Clay-v1.5-L | 0.675 | 0.773 |
| Prithvi-EO-2 | 0.678 | 0.774 |
| U-Net (from scratch) | 0.648 | 0.782 |

Evaluation is **leave-one-region-out (LORO)** across 19 FloodPlanet and 14 UFO regions under a fixed
budget and seed with no validation-based checkpoint selection, which exposes the cross-region
generalization gap that random splits hide. See `results.md` and `ablation_component_results.md`.

## Installation

```bash
conda create -n floodduo python=3.12 -y && conda activate floodduo
pip install -r requirements.txt
```

## Data and pretrained weights (configure paths)

The FloodPlanet and UFO benchmarks are public:
- FloodPlanet: https://zenodo.org/records/19698577
- UFO: https://zenodo.org/records/15238572

Point the code at the data and (optional comparative) checkpoints via environment variables:

```bash
export FLOODBENCH_ROOT=/path/to/floodbench   # contains floodplanet_planetScope/ and UFO/
export RUNS_ROOT=runs/loro                    # where LORO fold outputs are written
```

Pretrained encoder weights:
- **DINOv3-L** is fetched automatically via `timm` (`vit_large_patch16_dinov3.lvd1689m`).
- **Clay v1.5** and the comparative baselines (DOFA, Prithvi, CROMA, TerraMind, SSL4EO-DINO) expect
  their checkpoints under `pretrained/` (see the paths in `src/models/*_encoder.py`).

Expected data layout (identical for both datasets):
```
$FLOODBENCH_ROOT/floodplanet_planetScope/{train,val,test}/{image,mask}/*.tif
$FLOODBENCH_ROOT/UFO/{train,val,test}/{image,mask}/*.tif
```
Images: 4×1024×1024 float32 surface reflectance; masks: 1×1024×1024 uint8 {0,1}.

## Training

```bash
# train the champion architecture on one benchmark (per-dataset independence)
python -m src.train --config configs/arch6_fp.yaml     # FloodPlanet
python -m src.train --config configs/arch6_ufo.yaml    # UFO
```

## Evaluation

```bash
python -m src.eval --run runs/<name> --dataset floodplanet
```

## Reproducing the cross-region (LORO) results

Each fold trains on all regions but one and evaluates on the held-out region:

```bash
# a single fold
python -m src.loro_fold --dataset floodplanet --region Bolivia \
    --epochs 80 --lr 5e-4 --model-config configs/arch6_fp.yaml --device cuda:0

# full LORO sweeps (multi-GPU runners)
bash scripts/run_loro_arch6.sh          # FloodDuo, both datasets
bash scripts/run_loro_unet.sh           # U-Net baseline
bash scripts/run_loro_comparative.sh    # frozen-FM baselines
python scripts/show_loro.py             # print the region-wise IoU tables
```

## Component ablation

```bash
bash scripts/run_loro_ablation.sh       # Base -> +EA -> +ADAC -> +PPAdapter ladder
bash scripts/run_loro_fusiononly.sh     # fusion without adapters (interaction test)
python scripts/show_ablation.py         # print the ablation tables
```

## Figures

Paper figures are regenerated by the `scripts/fig_*.py` scripts (boxplots, precision–recall,
boundary error, disagreement calibration, gate routing, efficiency, failure modes, representation
analysis, etc.).
